# GNS 201: Communication in English

Complete professional communication course for Nigerian students.

## Course Contents

- **Chapter 1:** Registers in Professional Communication (10 professions, 30 registers each)
- **Chapter 2:** Business Correspondence (Application, Inquiry, and Complaint Letters)
- **Chapter 3:** Writing for Publication (Articles, Essays, Feature Writing)
- **Chapter 4:** Report Writing (Analytical Reports, Proposals)

## How to Use

1. Open `index.html` to see course homepage
2. Click on each chapter link to access content
3. Each chapter includes 11 exam-style questions
