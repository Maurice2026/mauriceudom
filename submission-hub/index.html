1. Definition of Plagiarism

Plagiarism is presenting someone else's work, ideas, or words as your own without proper attribution. This includes direct copying, paraphrasing without citation, collusion, self-plagiarism, and inadequate citations.

2. Detection Methods

All submissions are checked using plagiarism detection software, peer comparison, manual instructor review, source verification, and metadata analysis to ensure originality.

3. Consequences of Academic Dishonesty

Violations result in: immediate zero grade, formal academic report, disciplinary action, course grade reduction, and potential legal consequences for copyright infringement.

4. How to Avoid Plagiarism

Always cite sources using proper format (APA, MLA, Chicago), use quotation marks for direct quotes, paraphrase correctly with citations, start early, and consult instructors when unsure about citation practices.
